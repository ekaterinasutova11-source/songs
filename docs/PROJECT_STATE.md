## Код

### Оглавление и плеер

В репертуаре теперь компактный список песен с поиском и сортировкой. Полная
карточка с вариантами, текстом, переводом, заметками и редактором открывается
на отдельном маршруте `/song/<ключ песни>` внутри существующей ссылки.
Личные ссылки и структура данных не меняются. Названия в адресах кодируются;
неправильное кодирование обрабатывается без падения. После переименования песни
адрес её открытой страницы обновляется. Общий поиск преподавателя также ведёт
на отдельные страницы.

Плеер: отмена жеста, потеря фокуса и смена источника сбрасывают незавершённое
перетаскивание. Перемотка блокируется до корректной длительности, значения
ограничены длиной записи, исключения браузера не замораживают обновления.
Закрытие плеера освобождает источник; запоздалые результаты запуска старой
записи не меняют состояние новой.

Полная загрузка и декодирование ради волны больше не запускаются автоматически
при выборе трека: кэш используется сразу, новая волна строится кнопкой.
Автотемп без сохранённого результата запускается кнопкой «Авто»; сохранённые
настройки и ручной BPM продолжают работать.

62 теста проходят, включая маршруты с Unicode, отмену перемотки, смену источника,
ошибку установки currentTime, клавиатуру и ограничение позиции. В браузере
проверены преподавательский и ученический списки, страницы, возврат, смена
варианта, фактическое воспроизведение и перемотка (25,211 с, бегунок 100/1000
при длительности 252,110 с). Проверена ширина 390 px. Физические iOS/Android
не проверялись; работа в фоне требует отдельного пилота.

Снимки интерфейса находятся в игнорируемой `outputs`. Основной файл
`index.html` ссылается на `app.js?v=songpages1`, обновлён параметр CSS.

## Обнаруженная неисправность

### Восстановление завершено

Владелец вошёл в Яндекс и подтвердил: для двух новых дуэтов ссылки ещё не
выдавались. Поэтому сохранены 9 уже выданных ключей из проверенных копий,
а для двух дуэтов созданы первые ключи. Сохраняются также исторические записи
настроек, не соответствующие нынешним папкам; они не дают доступ к другим папкам.

В Яндекс загружен НОВЫЙ приватный файл настроек, проверены SHA-256 и отсутствие
публичного доступа. Исходный недоступный файл сохранён. Его отдельная копия
также сохранилась на Диске; она воспроизводит ту же ошибку чтения и не используется.

Cloud Function переключена на проверенный файл. Версия `d4e07h4gnaj04ca5797t`
активна. Ключ преподавателя, токен Диска, корневая папка, runtime, память и
таймаут сохранены. Защита от автоматического сброса ссылок развёрнута.

Итоговая проверка:

- Основной сервер, без Google fallback: кабинет преподавателя, 11 пространств,
  все метаданные доступны. Браузер показывает 11 страниц и 78 песен.
- Каждый из 11 ученических ключей открывает только своё пространство.
- Все 9 ранее выданных ключей совпадают с проверенным резервом.
- Неизвестный ключ и попытка читать чужую папку получают HTTP 403.
- Текст целиком и первые 65 536 байт MP3 совпали с местным снимком.
  Аудио отдаётся с HTTP 206, поддержка Range проверена.
- При промежуточной проверке был единичный HTTP 500; итоговая проверка всех
  11 входов прошла с первого раза, без повторов. Отказоустойчивость Яндекса
  этим не гарантируется; перенос с Диска остаётся в плане.

Новые ссылки сохранены в `secrets/Ссылки новых дуэтов.txt`; доступны также через
кнопки копирования ссылок на странице преподавателя. Не включать их в Git.
В местном снимке добавлена папка `control` с проверенными восстановленными
настройками. Его материалы по-прежнему содержат 233 файла.

### Диагностика до восстановления

Прямое скачивание текущих настроек, включая Range-запрос, возвращает HTTP 500
с текстом `file IO failure: no more reliable hosts`. Метаданные доступны:
размер 1 331 байт, изменение 14 октября 2026 года. Содержимое не восстановлено;
служебный файл не перезаписывался. WebDAV с существующим токеном вернул 401.

Исторические настройки от 13 октября содержат 10 записей, из которых 9
соответствуют нынешним 11 папкам. Все 9 ключей Google-резерва совпадают с ними.
Хеш исторического файла отличается от текущего. Подмена старой копией не
сохранила бы доступ к двум нынешним пространствам и не выполняется.

История файла в браузере не дала более новой читаемой копии с двумя новыми
пространствами. Подтверждение владельца об отсутствии выданных ссылок позволило
восстановить их без замены ранее выданных ключей.

Локально добавлена защита `loadState`: отсутствие или некорректная структура
настроек при существующих папках больше не запускает автоматическую замену
ключей. Добавление папки при исправных настройках сохраняет прежние ключи.
55 тестов проходят. Защита развёрнута вместе с переключением на новый файл.

Частные результаты диагностики находятся в `secrets/recovery-2026-10-19`.
`scripts/diagnose-settings.mjs` выполняет только чтение и сохраняет подписанные
ссылки и метаданные исключительно в эту игнорируемую папку.

Основная Cloud Function дважды вернула HTTP 502 при чтении библиотеки.
Прямой доступ к каталогу Яндекса работает. При прямом чтении настроек доступа
ссылка на скачивание получена, но содержимое вернуло HTTP 500.
Это сужает диагностику до чтения служебного файла, но не доказывает его
необратимую порчу. Он не заменялся и не пересоздавался.

Содержимое неисправного исходного файла получить не удалось. В снимок добавлены
проверенные восстановленные настройки с сохранением всех ранее выданных ключей.

## Утилиты

- `scripts/audit-materials.mjs`: проверка старого резерва, каталог Яндекса,
  сравнение с резервом и тестовое чтение Google. Частные отчёты пишет в
  игнорируемую `secrets/audit-2026-10-19`. Проверка primary library — только
  с `--probe-primary-library`, поскольку старый обработчик может создавать ключи.
- `scripts/backup-audited-materials.mjs`: создаёт НОВУЮ папку снимка по частному
  каталогу, проверяет размер и хеши. Ничего не перезаписывает в источниках.
- `scripts/probe-materials-backup.mjs`: FFprobe-проверка копии. Использует
  временные ASCII-ссылки, поскольку установленный FFmpeg не открывает некоторые
  Unicode-имена напрямую.

Аргументы с расположением предыдущей рабочей папки и новым назначением указываются
явно. Для новых дат следует изменить каталог частного отчёта в утилитах.
