# Сад звука — мобильное приложение

Первая тестовая версия Flutter для Android и iPhone/iPad. Сайт работает параллельно;
API, материалы и права общие, на Selectel. Windows-цели нет.

## Что есть в версии 0.1.0

- Вход вставкой существующей личной ссылки: поддерживаются прежний GitHub Pages
  и новый Selectel, включая ссылки на отдельную песню.
- Сохранение входа по выбору пользователя в Android secure storage / iOS Keychain.
  Личные ссылки и ключи не встроены в приложение и не выводятся в сообщения ошибок.
- Библиотека ученика, поиск, группировка минусов/плюсов/оригиналов как на сайте.
- Страница песни: варианты аудио, TXT, перевод, заметки, импульс (просмотр).
- Один нативный плеер: play/pause, перемотка, ±10 секунд, скорость 0.75/1/1.25,
  повтор целой записи. Подготовлены сервис Android и аудиофон iOS.
- По учительской ссылке — просмотр действующих и архивных пространств.
  Администрирование и редактирование пока выполняются на сайте.
- Ответ 403 убирает материалы с экрана и останавливает плеер. Проверка библиотеки
  выполняется при возврате в приложение и периодически, пока среда даёт работать
  Dart-коду. Уже загруженные/буферизованные байты нельзя мгновенно отозвать.
- Выход сразу закрывает интерфейс, отменяет применение поздних ответов, удаляет
  сохранённый ключ последовательно с возможной незавершённой записью хранилища.

Автоматическое открытие приложения по нажатию ссылки (App Links / Universal Links)
ещё не настроено: в первой версии ссылку нужно вставить. Материалы не скачиваются
для офлайн-библиотеки. Нет загрузки/изменения материалов, архивирования из приложения,
волны, A–B-повтора и метронома. Иконка установщика пока штатная Flutter.

## Платформы и инструменты

- Flutter stable 3.47.7, Dart 3.13.5; зависимости закреплены `pubspec.lock`.
- Android 7+ (API 24), target/compile 36. iOS 15+ — минимум текущего шаблона.
- Идентификатор для разработки: `ru.sadzvuka.songs`, не зарегистрирован в магазинах.
- Flutter `D:/devtools/flutter`, JDK 17 `D:/devtools`, Android SDK
  `D:/devtools/android-sdk`. SDK/JDK получены из официальных источников с проверкой
  опубликованных контрольных сумм. Android Studio/эмулятор не устанавливались.
- Android Gradle cache `D:/devtools/gradle-cache`. `kotlin.incremental=false`
  обходит конфликт путей проекта на D: и pub cache на C:.
- Шрифты Manrope и Cormorant локальные; их OFL-лицензии включены в assets.
- Новый платный сервис не подключён. Apple-аккаунты, Xcode Cloud и TestFlight
  не настраивались: этот этап отложен пользователем.

## Команды на этом компьютере

Из каталога `mobile` в PowerShell:

```powershell
$env:GRADLE_USER_HOME = 'D:/devtools/gradle-cache'
& D:/devtools/flutter/bin/flutter.bat pub get
& D:/devtools/flutter/bin/flutter.bat analyze
& D:/devtools/flutter/bin/flutter.bat test --timeout 60s
& D:/devtools/flutter/bin/flutter.bat build apk --debug
```

APK: `build/app/outputs/flutter-apk/app-debug.apk`. Это сборка с отладочной
подписью для тестовой установки, не пакет для публикации в магазине.
Обновления из магазина и постоянный ключ подписи ещё предстоит настроить.
На новом компьютере использовать собственные пути SDK и выполнить `flutter doctor`.

Безопасная проверка API (только чтение) на компьютере владельца:

```powershell
& D:/devtools/flutter/bin/dart.bat run tool/verify_selectel.dart
```

Она читает существующий закрытый `../secrets/teacher.env` и частный baseline
переноса; не передавайте эти файлы разработчикам/ученикам. Проверяет учительскую
и изолированную ученическую библиотеку, TXT и Range 0–1023 аудио. В отчёте
`../outputs/mobile-selectel-verification.json` только числа, без имён и ключей.

- 75 прежних серверных/веб-тестов прошли; код сайта и сервера не менялся.
- `../outputs/mobile-song-preview.png` — рендер Flutter widget-теста с вымышленными
  материалами, а не снимок работающего телефона.

## Следующая обязательная проверка на устройстве

На Android установить тестовый APK и вставить личную ссылку. Проверить:

1. Список, поиск, открытие песни, TXT/перевод/заметки, вход после перезапуска.
2. Play/pause, seek на паузе и при игре, продолжение после seek, смену варианта.
3. Скорость, повтор, проводную/Bluetooth-гарнитуру, уход в фон и блокировку экрана.
4. Потерю/возврат сети, истёкшую ссылку медиа и повторную загрузку.
5. На временном ученике — архив/восстановление с сайта, отказ в приложении и
   возврат по тому же ключу. Настоящих учеников ради теста не архивировать.
6. Выход во время загрузки, повторный запуск без сохранённого входа.

Физического телефона/эмулятора в текущей сессии не было. Само воспроизведение,
фоновый сервис и поддержка кодеков на Android/iOS ещё не подтверждены устройством.
iOS не собиралась; необходим согласованный Mac, signing и TestFlight. Не выдавать
успешный APK-build и widget-тесты за проверку звука на телефоне.
